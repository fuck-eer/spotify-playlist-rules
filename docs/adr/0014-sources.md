# ADR-0014: Sources limited to owned, collaborative, Liked Songs

Status: Accepted (Nishchay, 2026-10-16)

## Context

Spotify only lets an app read items of playlists the user owns or collaborates on.

## Decision

Sources in v1: owned playlists, collaborative playlists, and Liked Songs. Followed playlists are hidden from the source picker in v1.

## Consequences

Spotify-made / other users' playlists need a manual copy first (existing hint copy).
